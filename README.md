# 🎨 React Background Changer

A simple and interactive **Background Changer** web application built with **React.js**. Users can instantly change the background color by selecting different color buttons.

## 🚀 Features

* 🎨 Change background color instantly
* ⚛️ Built with React.js
* 🔄 Uses React `useState` for dynamic color changes
* 📱 Simple and responsive interface
* ✨ Clean and minimal UI
* ⚡ Fast development with Vite

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML
* CSS
* Vite
